# HW_Functional_Programming_in_Python
 Functional_Programming_in_Python

### Задачи:

    1. Реализовать рекурсивную функцию, которая выводит только нечетные числа из переданного списка на консоль.

    2. Реализовать рекурсивную функцию для подсчета элементов в списке.

    3. Написать функцию, которая при каждом следующем своем вызове выводит на консоль следующий элемент заданного списка.
